# BloomAura - Personal Blog

## 📋 Project Overview

BloomAura is a responsive personal blog template built with HTML, CSS, and JavaScript. It features a clean, modern design with a light color scheme, soft shadows, and elegant typography. This template is designed to provide bloggers and content creators with a professional, mobile-first website that showcases their work beautifully across all devices.

## 🌟 Features

- **Fully Responsive Design**: Optimized for all devices from mobile phones to large desktop screens
- **Modern Aesthetic**: Light background with soft shadows and pastel accent colors
- **Elegant Typography**: Serif/sans-serif font pairing (Playfair Display and Inter)
- **Interactive Elements**: Smooth animations, hover effects, and scroll behaviors
- **Optimized Images**: Local image storage for faster loading times
- **Form Validation**: Client-side validation for the newsletter subscription form
- **Bootstrap 5 Framework**: Utilizing the latest Bootstrap features for layout and components

## 💻 Technologies Used

- **HTML5**: Semantic markup for structure and accessibility
- **CSS3**: 
  - Custom properties for consistent theming
  - Flexbox and Grid for responsive layouts
  - Media queries for different device sizes
  - Animations and transitions for interactive elements
  - Custom scrollbar styling
- **JavaScript**: 
  - DOM manipulation for dynamic content
  - Form validation for the newsletter
  - Smooth scrolling implementation
  - Intersection Observer API for scroll animations
- **Bootstrap 5**: 
  - Responsive grid system
  - Component styling (cards, buttons, badges)
  - Utility classes for spacing and layout
- **Bootstrap Icons**: Icon library for social media and UI elements
- **Google Fonts API**: Web fonts (Playfair Display and Inter)
- **CSS Custom Properties**: For theme color management
- **Mobile-First Design**: Built with progressive enhancement approach

## 📱 Page Structure

1. **Top Header**: "New Post Every Week" badge and social media icons
2. **Logo Header**: Centered logo with navigation links
3. **Hero Section**: Welcome message with call-to-action button
4. **Featured Posts**: Horizontally scrollable blog post cards
5. **About Me**: Author introduction with circular portrait
6. **Topics Section**: Category cards for Travel, Design, Code, and Lifestyle
7. **Reading List**: Book recommendations with ratings
8. **Newsletter Sign-Up**: Email subscription form with validation
9. **Instagram Feed**: 6-image grid preview with hover zoom effect
10. **Contact Me**: Simple contact section with button
11. **Footer**: About information, quick links, and resources
12. **Bottom Bar**: Copyright information and credits

## 🚀 Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/soikot-shahriaar/BloomAura.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd BloomAura
   ```

3. **Open in your browser**:
   - Simply open `index.html` in your web browser to view the template
   - Or use a local development server for better development experience

4. **Customize the content**:
   - Edit `index.html` to update text content
   - Modify `style.css` to change colors and styling
   - Update `script.js` for custom functionality
   - Replace images in the `images/` folder with your own
